概要




🟢 STEP 1: Read specification like a story

Ask:

Who starts the process?
What triggers stacking?
What is input?
What is output?
What can go wrong?

👉 Write in simple English or broken Japanese.

🟢 STEP 2: Extract 5 key things

From spec, identify:

1. Actors
Operator
PLC
System (WCS)
2. Inputs
signal ON
command request
3. Outputs
stack complete
error signal
4. States
idle
running
error
5. Flow
step by step process

🟢 STEP 3: Convert into diagrams

Then you draw.

🧠 4. Simple mental model (VERY IMPORTANT)

Think like this:

🟢 Context diagram = “map of world”

who exists around system

🟢 Use case = “what users do”

actions

🟢 State diagram = “mood of system”

system condition changes

🟢 Activity = “recipe”

step-by-step cooking process
